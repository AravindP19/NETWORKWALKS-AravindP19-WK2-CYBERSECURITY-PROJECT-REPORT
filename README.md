# 3. Activities Performed

## 3.1 OSINT Footprinting (microsoft.com)

I also utilized theHarvester to perform broad OSINT collection against `microsoft.com`.
-   Running `theHarvester -d microsoft.com -l 1000 -b all` revealed missing API keys for services like bevigil, Bitbucket and BuiltWith which limited the data sources available.
-   A targeted search using `theHarvester -d microsoft.com -l 1000 -b baidu` yielded no IPs, emails, or hosts from the Baidu search engine.

## 3.2 Network Scanning with Zenmap

For internal discovery, I scanned my local network.
-   I used the `ip a` command to identify my local network interface (`eth0`) and IP address (`192.168.1.8/24`).
-   I used Zenmap to run a ping Scan (`nmap -sn 192.168.1.0/24`) on the `192.168.1.0/24` subnet. This identified two live hosts: `192.168.1.1`, and `192.168.1.6`.
-   The scan exposed the MAC addresses. I then saved the visual network topology generated by Zenmap.
